## ✨ Особенности

*   **Реалистичный интерфейс:** Деревянная текстура стола, объемные костяшки с тенями и плавные анимации перемещения.
*   **Построение «змейки»:** Костяшки на столе автоматически поворачиваются на 90 градусов, выкладываясь в классическую извилистую линию.
*   **Умный ИИ (упрощенный):** Компьютер играет по заданному алгоритму — всегда выбирает самую крупную доступную костяшку (по сумме очков). Это делает игру быстрой и предсказуемой.
*   **Классические правила:** Раздача по 7 костей, обязательный ход дублем 6-6 при наличии, «базар» (взятие костей из оставшихся).
*   **Полностью на Frontend:** Чистый HTML, CSS и JavaScript. Не требует серверной части или баз данных.

## 🛠 Технологический стек

*   **HTML5** — структура игрового поля и интерфейса.
*   **CSS3** — анимации, тени, текстуры дерева и адаптивная верстка. Используются Flexbox и Grid.
*   **Vanilla JavaScript (ES6+)** — вся игровая логика, работа с DOM и управление состоянием.

Проект не требует сборки (Webpack/Vite) и запускается в любом современном браузере.

Если вы развернули репозиторий на GitHub:

## 🎮 Правила игры

1.  **Начало:** Вам и компьютеру раздается по 7 случайных костей. Если у кого-то есть дубль `[6|6]`, он выкладывается в центр. Если дубля нет у обоих, игру начинает человек.
2.  **Ход:** Вы можете положить кость, если одно из её чисел совпадает с числом на конце «змейки» (левой или правой крайней костяшки).
3.  **Если нет хода:** Нажмите кнопку **«Брать кость»**, чтобы взять одну из оставшихся на базаре. Если базар пуст, нажмите **«Пас»**.
4.  **Победа:** Побеждает тот, кто первым выложит все свои кости.
5.  **«Рыба»:** Если ни один игрок не может сделать ход, а кости в базаре закончились, игра блокируется. Побеждает тот, у кого сумма очков на оставшихся костях меньше.

## 🤖 Логика ИИ

Компьютерный оппонент играет по очень простой, но агрессивной стратегии:
*   Перед каждым ходом его рука сортируется по убыванию суммы очков на костяшке (от `[6|6]` до `[0|0]`).
*   ИИ берет первую подходящую кость из этого отсортированного списка.
*   Если подходящих костей нет, ИИ берет одну с базара. Если базар пуст — пасует.
